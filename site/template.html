Duska line rebuild

An independent reconstruction of Kevin J.S. Duska Jr.'s father's-father line, built one desktop folder at a time. Each batch gets a blurb, a set of hypotheses with stated odds, and a ruling on the ones already open. The result will be compared with the tree Kevin built himself.

    Lineage

    Direct line by Ahnentafel number. A dashed label means no record supports the entry yet.

    Family groups

    Couples and their children as rebuilt from the baptisms. All are unplaced: none is yet tied to the direct line by a record. Years in square brackets come from the owner's file names.

    Unplaced candidates

    People proved by a record whose link to the direct line is still a hypothesis.

    Batch log

    Newest first. One entry per delivery of files.

    Hypotheses

    Each one is a prediction that a later record can confirm or kill. Confidence is the analyst's own estimate at the latest batch.

    Documents

    Every file received, by folder, with an entry-by-entry abstract in English. Passages that matter are transcribed and translated in full; square brackets mark doubtful readings. Select an image to open it full size.

    Curiosities

    Things in the records that are not about the Duskas and are worth keeping anyway.

    Folder register

    Desktop folders as Kevin describes them. A folder stays open until he says it is complete.

    Known before Batch 1

    Things the analyst had already been told or had glimpsed. They are logged here so the comparison stays honest, and they do not count as findings.

    Outside leads

    From public catalogues and searches, independent of Kevin's archive. Unverified until a record is in hand.

    Cross-review

    At the start of each batch this agent reads the Demko agent's repository and checks it against the Duska line.

    Request queue

    Material the analyst would ask for. Held until a whole line has been processed from the folders given.
